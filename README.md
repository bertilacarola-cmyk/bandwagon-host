# 搬瓦工套餐怎么选：线路、机房与购买前的比较指南

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 品牌，提供不同资源配置、网络线路和机房选择的服务器方案。对于准备学习 Linux、部署个人网站，或比较海外服务器的读者，挑选时不能只看最低价格：预算、资源需求、访客位置、线路、可迁移机房和付款周期都需要放在一起考虑。

本文根据已有资料整理常规方案与历史限量方案，帮助读者先确定比较顺序，再到对应页面核对实际销售条件。表格中的配置和价格是资料所列信息，不代表实时库存或当前报价。

## 先确定需求，再比较套餐

购买前先写下服务器的主要用途：是练习系统管理、运行个人网站，还是为不同地区的访客提供服务？再估算可接受的支出，以及每个月大致需要传输多少数据。这样可以把选择范围缩小到资源、区域和周期都合适的方案，而不是仅凭套餐名称决定。

配置表中的数字各自回答不同问题：

- **CPU 和内存**：分别用于衡量可分配的计算资源和运行空间。比较时应结合准备安装的软件及其需求，而不是仅凭核数判断某个业务能否运行。
- **SSD 容量**：决定系统、程序和数据可用的存储空间。除了网站文件，还应考虑日志和更新所需空间；表中 SLA 方案列的是 NVMe 存储。
- **月流量**：反映每月的数据传输额度。访客下载内容、上传文件和日常管理都会产生传输，选购时应留出余量，并确认具体计量规则。
- **带宽**：表内以 Gbps 标示，是与连接速率有关的参数，不等同于每月流量额度，也不能单独作为实际访问速度的保证。

计费周期同样影响决策。月付便于按月安排支出，季付和年付则需要一次支付更长周期的费用；比较时应看完整周期的总额，而不是把不同周期的数字直接相减。资料列出的部分方案有多种周期，但不是每个方案都列出了月付价格。下单前还应核对续费条件、库存和套餐页面上的可用机房。

## 线路与机房：应该看哪些差异

如果访客主要分布在特定地区，机房位置和其连接到访客网络的路径都值得关注。相同地点不意味着所有运营商的访问路径相同；反过来，线路名称也不能单独决定每个地区的实际表现。比较时应把访客所在地、使用的运营商和可选机房一起看。

参考资料提到了以下线路：

- **CN2 GT**：资料将其描述为电信 CN2 的中端线路，回程使用 CN2，去程可能经过普通骨干网；KVM 套餐的部分机房使用该线路。
- **CN2 GIA**：资料将其描述为电信去程、回程均使用 CN2 的线路。CN2 GIA-E、香港和大阪方案均涉及这一线路。
- **CMIN2**：中国移动精品骨干网，资料称 DC6 和 DC9 已接入。
- **CUP（AS9929）**：联通精品网，资料称 DC6、DC9 和 EUNL_1 等机房已接入。
- **日本大阪软银**：这是资料中另行提到的大阪线路选项；它与大阪 CN2 GIA 方案不是同一个线路名称，比较时应看具体套餐和机房说明。

资料对 CN2 GIA-E 的 DC6、DC9 描述包含电信 CN2 GIA、移动 CMIN2 和联通 CUP。若国内访客使用不同运营商，可以把这些信息作为筛选依据，但不要把线路名称当作所有时间、所有地区速度的承诺。需要重视访问表现时，应结合目标用户网络进行测试和判断。

### 搬瓦工机房怎么选

先区分“初始机房”和“套餐允许迁移的机房”。例如，资料列出的 CN2 GIA-E 方案可选择的地点包括洛杉矶 DC6、DC9、温哥华、大阪软银及荷兰 EUNL_9；香港方案则列有香港、新加坡、东京和大阪等 CN2 GIA 地点。可迁移范围因套餐而异，不能假设每种方案都能切换到全部地点。

入门 KVM 的可选地点也包括美国及阿姆斯特丹等机房。参考资料特别指出，该套餐切换到洛杉矶 DC3 后流量变为原来的三分之一；如果流量预算紧张，迁移前尤其要核对这一规则。机房列表和迁移条件可能变化，购买前应以目标方案页面所列内容为准。

## 从下单到开始使用

1. **确认用途和预算。** 列出需要运行的软件、预估存储与月流量，以及访客主要地区。先确定必须满足的条件，再决定哪些项目可以取舍。
2. **打开对应方案页面。** 使用上表中与方案名称一致的入口，逐项核对 CPU、内存、存储、流量、带宽和可用机房。不要把一个套餐可迁移的地点套用到另一个套餐。
3. **选择付款周期并检查库存。** 比较该周期的应付总额和续费条件；如果所需配置缺货，重新核对其他周期或方案，而不是假设库存通知意味着可以立即下单。
4. **确认付款方式后完成购买。** 参考资料提到支持支付宝和银联；实际结算时应以页面显示的方式与金额为准。付款前再次确认所选方案、周期和机房。
5. **进入 KiwiVM 查看管理信息。** 资料提到该控制面板可获取 SSH 信息、重装系统和切换机房。开始操作前，先确认连接信息和目标系统；涉及重装时尤其要留意已有数据。

需要更换机房时，先查看套餐是否支持目标地点，以及切换后的流量规则；再做好数据备份，并通过 KiwiVM 进行迁移。即使资料描述了面板迁移功能，备份仍有助于在操作前保留自己的数据副本。迁移后也应检查服务和连接是否正常。

### 退款政策

参考资料称，新用户购买后 30 天内、流量消耗不超过 10% 时可以申请全额退款。申请条件与实际处理以购买时适用的条款为准；如可能需要退款，应尽早了解流量使用情况并阅读具体政策。

## 限量套餐、库存与优惠信息

限量方案适合愿意等待并能接受库存不确定性的读者。参考资料记录了三个历史实例：CN2 GIA-E 10G 限量版为 $49.99/年，列有 DC6、DC9、日本软银和荷兰等可切换机房；MINICHICKEN 约 $19/年，位于弗里蒙特，使用 HE 线路；The Tokyo Plan v2 约 $99/年，列为东京 DC39v2、CMI 线路和 2 核 2GB 配置。

这些是历史信息，并不表示目前仍在售或会按相同条件补货。若在意搬瓦工库存查询，资料提到的通知渠道有 Telegram 频道 **@BandwagonHostNews** 和 QQ 群 **451796455**。收到消息后仍应打开实际销售页面，核对方案名称、配置和价格，再决定是否购买。

关于搬瓦工优惠码，参考资料称截至 **2026 年 4 月**暂无通用优惠码，并提到此前短暂出现的 NODESEEK2026 已失效。这是有时间范围的记录，不能据此推断当前是否有优惠；也不要把历史代码当作有效折扣计算预算。若结算时有可用优惠，应核对它对首付款和续费的具体适用条件。

## 最后如何取舍

先用预算和付款周期筛选，再比较所需 CPU、内存、存储及月流量；随后根据访客位置、运营商和允许迁移的机房检查线路。对服务可用性有明确要求的读者，还应单独审阅 SLA 条款。价格较低、地理位置较近或参数较大都只是决策的一部分，不能替代对实际用途和销售条件的核对。
